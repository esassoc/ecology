Confirm Dialog

Confirmation modal driven by attributes. Resolves a boolean through confirm / cancel / resolved events. Esc cancels.

Stable wc import '@esa/ecology/esa-confirm-dialog'; Angular usage

Preview

Variants

Use warning for reversible-but-risky actions and danger for destructive ones.

API

PropTypeDefaultDescription
open boolean false Reflected attribute that drives visibility. Open imperatively via show().
heading string '' Title of the confirmation.
message string '' Supporting body text.
variant 'default' | 'danger' | 'warning' 'default' Icon and confirm-button color theme.
confirm-label string 'Confirm' Label of the confirm button. Property: `confirmLabel`.
cancel-label string 'Cancel' Label of the cancel button. Property: `cancelLabel`.
show-icon boolean true Renders the variant icon above the heading. Property: `showIcon`. On by default. Write `="false"` to turn it off — unusually for a boolean attribute, this one reads the value.
show-close-button boolean true Property: `showCloseButton`. On by default. Write `="false"` to turn it off — unusually for a boolean attribute, this one reads the value.
Binding these events from Angular

Every one of these is a CustomEvent, so the payload is on $event.detail — $event.target.value reads empty, with no error. The names are lowercase and Angular passes them to addEventListener verbatim, so camel-casing one means it never fires.

  • (dismiss)="onDismiss($event.detail)"
  • (resolved)="onResolved($event.detail)"

Methods

PropTypeDefaultDescription
show() method — Opens the dialog and focuses the confirm button.
confirm() method — Resolves true and closes.
cancel() method — Resolves false and closes.

Events

EventTypeDefaultDescription
confirm CustomEvent — Fired when the user confirms.
cancel CustomEvent — Fired when the user cancels (button, backdrop, or Esc).
resolved CustomEvent<{ confirmed: boolean }> — Fired on either outcome with the boolean result.

Accessibility

  • The panel is role="alertdialog" with aria-modal="true"; heading is the accessible name.
  • The confirm button receives focus on open; Tab and Shift+Tab cycle between the two buttons.
  • Escape and backdrop click both resolve as cancel; focus is restored on close.

Theming surface

Every public token this component reads, extracted from its source at build time, split by blast radius: the hooks that belong to this component, then the shared and system tokens it consumes alongside everything else. The Resolves to column walks each token's real lineage — component → semantic → primitive → raw value — so you can see exactly where re-pointing it lands. A spoke re-skins by overriding these in its theme-<slug>.css; component internals are never edited. No hook for what you need? File it with /request-lego.

Type roles it names

This component does not set a size, weight, face or tracking of its own — it names a composite, and the composite carries all five. A composite is a class rather than a token, so none of it appears in the tables below; re-theme text by re-pointing the token family, not by editing the component.
