Button Toggle

A segmented single-select — one-of-N choices rendered as a row of connected buttons. Form-associated, holds the selected value, and follows the WAI-ARIA radiogroup pattern with arrow-key navigation.

Stable wc import '@esa/ecology/esa-button-toggle'; Angular usage

Preview

Sizes

Four sizes share the form scale. Default is md.

Icons

Each option may carry an icon — inner Lucide SVG markup (the same paths convention as esa-icon). It renders before the label and inherits currentColor, so it flips to the inverse color on the selected segment.

Omit label for an icon-only segment — set ariaLabel so it still has an accessible name.

States

error-text replaces help-text in the slot below the group and reddens the track — the same one-slot precedence esa-select and esa-text-field use, so the two messages never stack.

Form participation

The control submits its selected value under its name. Submitting logs the view entry.

With required, the group reports valueMissing through ElementInternals until something is selected, so the native form refuses to submit and checkValidity() returns false — the asterisk is not the whole of it.

API

PropTypeDefaultDescription
label string '' Optional visible label above the group; becomes the radiogroup name.
help-text string '' Helper text below the group. Property: `helpText`.
error-text string '' Validation message below the group. Replaces help-text and reddens the track. Property: `errorText`.
options EsaToggleOption[] [] The segments. Set as a property (an array, not an attribute). Optional icon is inner Lucide SVG markup (the same paths convention as esa-icon), rendered before the label and inheriting currentColor. Omit label for an icon-only segment, but then set ariaLabel for its accessible name.
value string '' Selected option's value. Single-select; bound to the form value.
size 'xs' | 'sm' | 'md' | 'lg' 'md' Control size (shared form scale).
name string | undefined — Form field name — the key this control submits under.
disabled boolean false Disables every segment.
required boolean false Blocks submission while nothing is selected (valueMissing), and adds an asterisk plus aria-required.

Events

EventTypeDefaultDescription
change CustomEvent<{ value: string }> — Fired when the selection changes. Composed and bubbling; detail.value is the newly selected value.
Binding these events from Angular

Every one of these is a CustomEvent, so the payload is on $event.detail — $event.target.value reads empty, with no error. The names are lowercase and Angular passes them to addEventListener verbatim, so camel-casing one means it never fires.

  • (change)="onChange($event.detail)"

Accessibility

  • Renders role="radiogroup" wrapping role="radio" buttons with aria-checked reflecting selection.
  • Roving tabindex: only the selected (or first) segment is tab-reachable; Arrow keys move selection through the group, wrapping at the ends.
  • Home and End jump to the first and last segments; Enter and Space select the focused segment.
  • The label becomes the group's accessible name via aria-labelledby.
  • Visible focus ring on the active segment via --focus-ring-* tokens; the focused segment is raised so its ring sits above neighbors.
  • Best for small fixed option sets — past about six options, prefer a select.

Theming surface

Every public token this component reads, extracted from its source at build time, split by blast radius: the hooks that belong to this component, then the shared and system tokens it consumes alongside everything else. The Resolves to column walks each token's real lineage — component → semantic → primitive → raw value — so you can see exactly where re-pointing it lands. A spoke re-skins by overriding these in its theme-<slug>.css; component internals are never edited. No hook for what you need? File it with /request-lego.

Wired to this component

None. This component has no hooks of its own — it themes entirely through the shared tokens below, so every override here also moves its siblings.

Owned by a family or by the semantic layer. Still overridable — but scope the override (esa-foo { --form-border-color: … }) unless you mean to move everything that reads it. Reach says what else that is.
