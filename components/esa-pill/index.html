Ecology / Display / Pill

Pill

Compact, rounded tag with color variants, sizes, an optional leading icon, and an optional remove control.

Stable .astro import EsaPill from '@esa/ecology/esa-pill.astro';

Preview

Variants

Sizes

Icon & removable

Pass a leading icon via the icon slot. With removable (the default), a × button emits a removed event and removes the pill from the DOM.

API

PropTypeDefaultDescription
label string required Required. Text shown inside the pill.
variant 'default' | 'primary' | 'success' | 'warning' | 'danger' | 'info' 'default' Color intent — drives background, text, and border.
removable boolean true Shows a remove (×) button.
size 'xs' | 'sm' | 'md' | 'lg' 'md' Pill height and text size.

Slots

PropTypeDefaultDescription
icon slot — Leading inline SVG, rendered left of the label.

Events

PropTypeDefaultDescription
removed CustomEvent — Bubbles when the remove button is clicked; the pill then removes itself from the DOM.

Accessibility

  • The remove button has aria-label="Remove"; the leading icon is aria-hidden.
  • Remove click stopPropagation()s so it won't trigger a click on a surrounding interactive container.
  • Color intent is reinforced by the label text — color is never the only signal.

Theming surface

Every public token this component reads, extracted from its source at build time, split by blast radius: the hooks that belong to this component, then the shared and system tokens it consumes alongside everything else. The Resolves to column walks each token's real lineage — component → semantic → primitive → raw value — so you can see exactly where re-pointing it lands. A spoke re-skins by overriding these in its theme-<slug>.css; component internals are never edited. No hook for what you need? File it with /request-lego.

Type roles it names

This component does not set a size, weight, face or tracking of its own — it names a composite, and the composite carries all five. A composite is a class rather than a token, so none of it appears in the tables below; re-theme text by re-pointing the token family, not by editing the component.
